Course topics

Spreadsheet Foundations

Organise a small list of fictional sales records and calculate a clear total.

  • Use meaningful column headings and consistent data formats.
  • Practise simple formulas, sorting and filtering.
  • Check a total against the original entries.

Practice output: a tidy sales worksheet with a checked total.

Reporting Basics

Turn a small set of fictional monthly raw figures into understandable business reports and KPIs.

  • State the question, reporting period and meaning of each measure.
  • Compare values in a clear table or simple chart.
  • Explain one finding and one limitation in plain language.

Practice output: a short monthly performance summary.

Web Page Foundations

Create a small information page with a clear heading, navigation, an image and a labelled form.

  • Use HTML elements that describe the meaning of the content.
  • Connect pages with working relative links.
  • Check labels, alternative text and HTML validity.

Practice output: an introductory HTML web page you can explain.

Prepare for a practice session

  1. Choose one topic and write down what you want to learn.
  2. Use a computer with a browser and the appropriate editor or spreadsheet application.
  3. Work with sample data rather than confidential work records.
  4. Save your work and note what you would like to improve.
