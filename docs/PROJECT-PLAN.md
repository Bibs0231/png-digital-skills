# Project plan

## Proposed concept

**PNG Digital Skills Hub** is a fictional educational service. It helps adult beginners in PNG compare three introductory topics and practise a course enquiry. Topic approval has not been established; confirm it before treating this theme as final.

## Problem and intended outcome

Beginners may know that they need computer skills but be unsure which topic supports their immediate work or study task. This website explains three starting points and their practice outputs, then offers a structured enquiry form. The A2 implementation demonstrates the enquiry interface, not a live training operation.

## User stories and acceptance checks

| User story | Acceptance check |
| --- | --- |
| As a beginner, I want to understand who the service is for so I can judge its relevance. | Home identifies the audience and practical learning goals. |
| As an office worker, I want to compare course outcomes so I can choose a suitable topic. | Courses provides three descriptions, a comparison table and a link to enquiry. |
| As an interested learner, I want clear enquiry questions so I can describe my needs. | Form labels, groups, help text and suitable controls support the enquiry. |
| As a keyboard user, I want to navigate without a mouse. | A manual test must confirm the skip link, visible focus, navigation and form sequence. |

## Sitemap

| Page | Navigation connects to | Key content |
| --- | --- | --- |
| Home | Home, Courses, Contact / Enquiry | Purpose, audience, learning diagram |
| Courses | Home, Courses, Contact / Enquiry | Course articles, comparison, preparation |
| Contact / Enquiry | Home, Courses, Contact / Enquiry | Proposed contact channel, form and practice explanation |

Within-page links also target course articles, the comparison table and the enquiry form.

## Simple page layout plan

Each page uses a visible skip link, shared site name and navigation, one main heading, grouped content and a shared footer. The courses page places the comparison after the detailed articles. The contact page places the practice-data notice before the form, then contact details, learning interests and acknowledgement in labelled groups.

## Scope and constraints

Three HTML pages; semantic structure; local diagram; a meaningful comparison table; substantial form; one basic external CSS file; no JavaScript, framework or downloaded template. No real contact details, payments or confidential datasets are needed. Advanced responsive layouts belong in A3; JavaScript interaction belongs in A4.
